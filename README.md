# Chess Tools

Browser-based chess training tools. Live at **https://djk321.github.io/ChessTools/**

- **Chess Board** — two-player board
- **Game Review** — paste a PGN and replay it move by move
- **Chess Openings** — browse 130+ openings with Stockfish analysis
- **Daily Puzzle** — the Lichess puzzle of the day
- **Round Robin** — 3-player round robin with pairings and standings
- **Coordinates Trainer** — learn the board squares against the clock

Plain HTML/CSS/JS — no build step. Part of the [Game Arcade](https://djk321.github.io/my-page/).
